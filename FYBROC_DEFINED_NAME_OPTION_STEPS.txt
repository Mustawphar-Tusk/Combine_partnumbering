Fybroc Defined Name Option Compiler
===================================

1. Extract this ZIP into the project root and merge folders.

2. Run tests:
   python -m pytest -q

3. Refresh discovery:
   python -m scripts.discover_workbooks

4. Compile Fybroc options:
   python -m scripts.compile_fybroc_defined_name_options

5. Review:
   exports\fybroc_defined_name_options.json
   exports\fybroc_defined_name_option_candidates.csv
   exports\fybroc_defined_name_option_issues.csv

Review summary:

Import-Csv .\exports\fybroc_defined_name_option_candidates.csv |
    Group-Object field_code |
    Select-Object Count,Name |
    Sort-Object Name |
    Format-Table -AutoSize

Review issues:

Import-Csv .\exports\fybroc_defined_name_option_issues.csv |
    Format-Table severity,issue_code,defined_name,message -AutoSize

This compiler imports descriptions only.
It does not guess hex-code columns.
Hex mappings will be compiled separately from the Attributes,
Pump Options, Seal Assembly, Options, and Motor Assy sheets.
