M013 Fybroc Series Constraint Matrix
====================================

1. Extract and merge into the project root.

2. Apply SQL:

   sqlcmd -S localhost -d PumpConfiguratorDB -E -C -b `
       -i .\sql\14_Create_Series_Field_Option_Metadata.sql

3. Run tests:

   python -m pytest -q

4. Refresh discovery:

   python -m scripts.discover_workbooks

5. Compile the matrix:

   python -m scripts.compile_fybroc_series_constraints

6. Review counts:

   Import-Csv .\exports\fybroc_series_constraint_candidates.csv |
       Group-Object field_code |
       Select-Object Count,Name |
       Sort-Object Name |
       Format-Table -AutoSize

7. Review issues:

   Import-Csv .\exports\fybroc_series_constraint_issues.csv |
       Format-Table severity,issue_code,message,source_reference -AutoSize

8. Load and publish into the current active publication:

   python -m scripts.load_and_publish_fybroc_series_constraints `
       --file .\exports\fybroc_series_constraint_candidates.csv `
       --publication-id 1

9. Test series projection:

   python -m scripts.test_fybroc_series_projection

Expected:
- 1x1.5x6 is valid for series 1530.
- 6x10x8 is not valid for series 1530.
- The returned sizes and materials come from SQL metadata.
