Segment Combination Compiler
============================

This compiler reads every valid segment combination row and derives
its code using the source ID and padded base-36 conversion.

Fybroc segments included:
- Pump Options: D:O, ID Q, width 4
- Seal Assembly: D:H, ID J, width 2
- Options: D:H, ID J, width 2

1. Extract and merge into the project root.

2. Apply SQL metadata:
   Set-Location .\sql
   sqlcmd -S localhost -d PumpConfiguratorDB -E -C -b `
       -i .\10_Create_Segment_Combination_Metadata.sql
   Set-Location ..

3. Run tests:
   python -m pytest -q

4. Refresh discovery:
   python -m scripts.discover_workbooks

5. Compile combinations:
   python -m scripts.compile_fybroc_segment_combinations

6. Review:
   exports\fybroc_segment_combinations.json
   exports\segment_combination_candidates.csv
   exports\segment_combination_issues.csv

Review counts:

Import-Csv .\exports\segment_combination_candidates.csv |
    Group-Object segment_code |
    Select-Object Count,Name |
    Sort-Object Name |
    Format-Table -AutoSize

Review issues:

Import-Csv .\exports\segment_combination_issues.csv |
    Format-Table severity,issue_code,worksheet_name,
        source_reference,message -AutoSize

The runtime will match a fully validated set of selections to exactly
one segment-combination row. It will not generate identifiers when
zero or multiple rows match.
