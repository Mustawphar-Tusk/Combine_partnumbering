  ConstraintTable1          Alt Size x CouplingGuard  [3 rows]

  ConstraintTable2          Alt Size x Flange Type  [1 rows]

  ConstraintTable3          Alt Size x Flush  [3 rows]

  ConstraintTable4          Alt Size x ImpellerTrim  [517 rows]
    Impeller Trims

  NO TABLE (series-derived) Alt Size x MotorHpRpm  [NOT RESOLVED]
    Series Depedent. From pump curves, only certain Horsepower and RPM combinations are available for each size.

  ConstraintTable5          Alt Size x Pump Material  [16 rows]
    We cannot make pumps in some materials. This can change on a case by case basis, some parts can be made in certain materials where as some parts can't be made in certain materials.

  ConstraintTable6          Alt Size x Shaft Material  [6 rows]
    5500 ONLY, Group 3 pumps with a wrapped shaft not allowed.

  ConstraintTable7          Casing Drains x Pump Material  [1 rows]
    Casings in VR-1V are not permitted to have Casing Drains. Purpose of VR-1V is to prevent fiberglass from being exposed to fluid.

  ConstraintTable8          CycloneSep x Flush  [6 rows]
    If you don't choose Cyclone Separator Flush, you can't just get Cyclone Separator.

  ConstraintTable9          Flush x Pump Material  [3 rows]
    Casings in VR-1V are not permitted to have taps for some flush options. Purpose of VR-1V is to prevent fiberglass from being exposed to fluid.

  NO TABLE (series-derived) Frame Size x MotorHpRpm  [NOT RESOLVED]
    Motor frames are only available in certain Horsepower and RPM combinations.

  NO TABLE (series-derived) MotorHpRpm x Motor Type  [NOT RESOLVED]
    Motor Horsepower and RPMs are only available in certain Motor Types.

  ConstraintTable10         MotorOption x Paint Upgrade  [2 rows]
    We can not supply Paint Upgrade if the motor is being supplied by the customer.

  ConstraintTable11         MotorOption x Shaft Grounding  [2 rows]
    We can not supply Shaft Grounding Rings if the motor is being supplied by the customer.

  ConstraintTable12         Pump Material x Setting  [15 rows]
    Verticals, No intermediate bearing material for EY-2, therefore only settings 1-4 are allowed.

  ConstraintTable13         Pump Material x Shaft Material  [2 rows]
    5500 ONLY, EY-2 and Wrapped Shafts are Now Allowed.

  ConstraintTable14         Pump Material x Sleeve  [2 rows]
    We do not make Separate Sleeve in EY-2, not VR-1V. Those are two materials that require the all FRP parts match due to chemical compatability.

  ConstraintTable15         Pump Material x Suction Discharge Taps  [1 rows]
    Casings in VR-1V are not permitted to have taps. Purpose of VR-1V is to prevent fiberglass from being exposed to fluid.

  ConstraintTable16         Seal Guard x Seal Option  [1 rows]
    If there is no gland, then we cannot supply a seal guard.

  ConstraintTable17         Seal Option x Seal Type  [5 rows]
    Must get a matching gland with seal.

  ConstraintTable18         Setting x Shaft Material  [8 rows]
    Wrapped shafts only come in Settings 1-4. Can't have intermediate bearings.

  ConstraintTable19         Shaft Material x Sleeve  [12 rows]
    For normal shafts, sleeve must be in the same material. For wrapped shaft, only allowed Hast-C or Titanium shaft sleeve. Shaft sleeve is not a separate Position number, it is included in Shaft part number.

  ConstraintTable20         Motor Control x Shaft Grounding  [1 rows]
    VFDs must get Shaft Grounding ring.

  ConstraintTable21         Pump Material x Length x Alt Size  [3477 rows]
    Verticals, No intermediate bearing material for EY-2, therefore only lengths up to Setting 4 for a size are allowed.

  ConstraintTable22         Setting/Length x Length  [183 rows]
    If Custom Length is selected, Length can be selected.

  ConstraintTable23         Setting/Length x Setting  [19 rows]
    If Standard Setting is selected, Setting can be selected.

  ConstraintTable24         Tailpipe Option x Tailpipe Length  [115 rows]
    If Tailpipe is Supplied, Tailpipe Length can be selected.

  ConstraintTable25         Seal Mfg x Seal Type  [30 rows]
    Seal Type must match Seal Manufacturer selected.

  ConstraintTable26         Seal Option x Seal Mfg  [25 rows]
    Seal Manufacturer depends on if Supplied by Fybroc or Installed by Fybroc is selected.

  ConstraintTable27         Wetted Hardware x Wetted Hardware Selection  [10 rows]
    Wetted Hardware Selection can only be selected if Custom Wetted Hardware is selected.

  ConstraintTable28         Flush Material x Flush  [18 rows]
    No flush material required if Internal Flush or External Flush are selected.

  ConstraintTable29         Alt Size x C-Face Adapter  [3 rows]
    C-Face adapter is not allowed on Group 3 pumps.

  NO TABLE (series-derived) Shaft Material x Sleeve x Wetted Hardware  [NOT RESOLVED]
