# M014.1 – Motor Frame Contextual Normalization

## Problem

The series applicability matrix stores NEMA frames with orientation suffixes:

```text
143T
284TS
```

The Motor Assembly combination table separates the same information:

```text
MOTOR_FRAME = 143
MOTOR_ORIENTATION = Hor T
```

A generic string intersection therefore returned no values.

## Decision

Use field-aware comparison keys. For `MOTOR_FRAME`, append the selected Motor Orientation suffix to combination values during comparison:

```text
143 + Hor T  -> 143T
284 + Hor TS -> 284TS
```

Display values remain unchanged. `T` and `TS` remain distinct.
