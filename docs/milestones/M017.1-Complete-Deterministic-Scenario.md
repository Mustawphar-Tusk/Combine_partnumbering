# M017.1 – Complete Deterministic Scenario

## Problem

M017 correctly removed silent fallback from the full-session test.
The prior preference profile defined only selected fields, so the
strict scenario stopped when it reached `SEAL_OPTION`.

## Resolution

The test scenario now defines an explicit expected choice for all 41
navigation fields.

This profile is a regression fixture only. It does not inject values
into runtime navigation. Each configured value must still be returned
by the current authoritative allowable projection.

## Protection

A new test compares the preference profile with the complete navigation
field order and fails when a field is missing, extra, or lacks an
`exact` or `contains` selector.
