# M014.2 – Motor Frame Stem Normalization

## Diagnostic Result

The two authoritative sources represent Motor Frame differently:

```text
Series applicability matrix:
143JM, 145JM, 182JM, ...

Motor Assembly combinations:
143, 145, 182, ...
```

The previous patch incorrectly derived `T` or `TS` from Motor Orientation.

## Decision

Use the numeric NEMA frame stem as the cross-source comparison key:

```text
143JM -> 143
143T  -> 143
143TS -> 143
143    -> 143
```

Motor Orientation remains constrained by the Motor Assembly combination table. Series applicability determines which frame sizes are permitted, not the Motor Assembly orientation/type suffix.
