# M016.1 – Fybroc Vocabulary Reconciliation

## Diagnostic Finding

The series applicability matrix and nomenclature combination tables use
different labels for the same engineering selections.

Examples:

```text
Not_Supplied_by_Fybroc ↔ No Casing Drains*
303_SS                 ↔ 303 SS Shaft*
Crane_8B2...           ↔ 8B2 Single Outside*
143JM                  ↔ 143
```

The supplied diagnostic identified every affected field for Series
1530. No constraint source is bypassed. fileciteturn12file0

## Resolution

A family metadata profile now declares field-specific equivalence
groups. The generic service consumes the profile; no Fybroc vocabulary
is hardcoded into API routes or shared projection logic.

## Combination-Only States

The `-` value is retained only when:

1. the current valid combination projection returns it; and
2. the field metadata explicitly declares it as a combination-only
   state.

This supports legitimate not-applicable paths without opening the
selection list.

## Nameplate Correction

`F_NamePlate` and `F_NamePlate2` are separate source fields.
`F_NamePlate2` maps to the nomenclature `NAMEPLATE` option; the first
field is retained separately as `NAMEPLATE_STANDARD`.
