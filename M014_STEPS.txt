M014 Unified Available Options Service
======================================

1. Extract and merge into the project root.

2. Run tests:

   python -m pytest -q

3. Run the live service test:

   python -m scripts.test_fybroc_available_options_service

Expected behavior:

SIZE:
- Uses ATTRIBUTE and SERIES filters.
- Returns the 16 valid sizes for Series 1530.
- 1x1.5x6 validates as true.
- 6x10x8 validates as false.

FLUSH:
- Uses SERIES and COMBINATION when a series relation exists.
- Returns only values compatible with the submitted Pump Options state.
- Workbook values such as External_Flush and External Flush*
  are matched through normalization.

MOTOR_FRAME:
- Uses SERIES and COMBINATION.
- Returns only frames compatible with the submitted Motor Assembly state.

This service is the core of the future endpoint:

POST /api/configuration/available-options
