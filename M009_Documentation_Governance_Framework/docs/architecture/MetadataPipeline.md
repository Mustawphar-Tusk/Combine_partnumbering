# Metadata Pipeline

1. Discover authoritative workbooks.
2. Inspect named ranges, validations, tables, formulas, and source coordinates.
3. Compile normalized fields, options, model references, identifiers, and segment combinations.
4. Export reviewable JSON and CSV artifacts.
5. Load candidates into isolated SQL staging.
6. Validate counts, uniqueness, JSON, widths, and lineage.
7. Publish approved metadata.
8. Generate runtime profiles and documentation.
