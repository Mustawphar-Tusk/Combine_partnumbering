# Configuration Engine

## Purpose
Resolve validated selections into ordered identifier segments and deterministic Part Numbers and SKUs.

## Current Capabilities
- SQL-backed PUMP_OPTIONS resolution
- SQL-backed SEAL_ASSEMBLY resolution
- SQL-backed OPTIONS resolution
- Ordered segment assembly
- Part Number and SKU generation

## Current Limitation
Simple attributes remain direct in the initial sample. M009 replaces them with SQL Attribute Resolver lookups.
